# Exoplanet preprint collection

Ten AI-assisted preprints on exoplanets, planetary systems, astrobiology, and technosignatures, dated August–October 2026. Experimental project 4 fun.

## Navigating the collection

- Use the [manuscript catalogue](CONTENTS.md) to browse all ten papers by title and subject, or locate an original `sci1.pdf`–`sci10.pdf` filename.
- The [preprints](preprints/) directory contains one title-and-date folder per manuscript. Each folder provides the original PDF as `paper.pdf`, a `README.md` with metadata, abstract, and a BibTeX citation, and `FullText.md` with extracted text from every page.
- See [history](history.md) for the organization record.

The organization follows the [OpenAI mathematics collection](https://github.com/openai/math): a root guide and manuscript map, with individual preprint folders. Folder names use the main title and the date printed in the manuscript; full titles and subtitles appear in the catalogue. The chemistry-to-life manuscript states only October 2026, so its folder has no invented day.

## Reading the text

Each `FullText.md` contains the PDF's extracted text, including its abstract, body, captions where embedded as text, and references. Page headings preserve the connection to the PDF. Reading order follows the PDF text stream, including sequential columns. Common ligatures, verified encoding errors, and unambiguous word splits at line breaks have been normalized; other line wrapping is retained. Figures, complex equations, and table alignment remain best viewed in the PDF.

## Versions and citations

The supplied PDF bytes are unchanged. Each manuscript README records the original filename and SHA-256 checksum and provides a BibTeX citation. All BibTeX entries use `autor = {{rafgro}}`. Author descriptions in the manuscript READMEs record the original title-page information.

This collection contains the ten supplied PDFs and their navigation and text files. Source code, datasets, LaTeX sources, and other supporting materials mentioned within the papers were not included in the supplied directory. The organization does not change or independently validate the manuscripts' scientific claims.
